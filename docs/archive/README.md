# 历史资料说明

本目录保存不再作为当前实现入口、但仍具有追溯价值的资料。

历史资料可能描述：

- 已被 TypeScript Runtime 替代的 Python 原型；
- 已完成或被后续 ADR 替代的实施方案；
- 特定时间点的迁移和恢复操作；
- 不再适用于当前产品面的行为。

阅读历史资料时应遵循以下优先级：

1. 当前代码和自动化测试；
2. `docs/architecture`、`docs/reference`、`docs/operations` 等当前说明；
3. 已接受且未被替代的 ADR；
4. 实施计划、Spike、验证记录和本目录历史资料。

历史文档顶部应明确标注其状态、替代文档或保留原因。发现历史内容仍被 README 或当前指南作为权威入口时，应修正链接，而不是直接删除追溯证据。
