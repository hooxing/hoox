## 阅读优先级

1. 当前代码、配置和自动化测试；
2. `docs/architecture`、`docs/reference`、`docs/operations` 等当前说明；
3. 已接受且未被替代的 ADR；
4. 实施计划、Spike、验证记录和本目录历史资料。

历史文档顶部必须标注其状态、当前替代入口或保留原因。发现当前 README 或指南仍把历史资料作为权威入口时，应修正入链，而不是现代化历史正文或删除追溯证据。
