# ADR-0003：PostgreSQL 与 S3/MinIO 持久化边界

- 状态：已接受
- 日期：2026-07-26
- 决策者：项目架构审阅
- 关联任务：M0-03、M1-01、M2、M4、M5
- 替代关系：无

## 背景

新系统从零实现，不兼容 Python 原型的 JSON/JSONL 和 `workspace.tar.gz`。它需要事务化保存领域状态和追加式 Rollout，同时保存 Workspace 文件、完整工具输出和交付物等大对象。开发环境已经具备 PostgreSQL 和 MinIO。

## 决策驱动因素

- 状态迁移、唯一性、Lease、幂等和 Tenant 归属需要事务与条件写；
- 大文件不能塞入数据库热表，且需要流式上传和预签名下载；
- PostgreSQL 与 S3 之间没有分布式事务，失败补偿必须明确；
- 开发和生产应使用同一套语义，避免本地 JSON 分叉。

## 备选方案

### 方案 A：全部保存到 PostgreSQL

事务简单，但大 Blob 会扩大备份、WAL 和数据库运维成本，也不利于直传下载。

### 方案 B：PostgreSQL 保存事实，私有 S3 保存 Blob

符合两类数据特征，但需要暂存、校验、补偿和孤儿对象回收协议。

### 方案 C：本地 JSON/文件与生产数据库双适配

本地启动更轻，但会产生两套事务和并发语义，旧原型兼容也会持续污染新设计。

## 选择

采用方案 B，并明确以下唯一正式语义：

- PostgreSQL 保存 Tenant、Thread、Run、状态机、Lease、Workspace/Resource/Artifact 元数据、内容引用、索引、幂等记录和追加式 Rollout；
- 私有 S3 兼容存储保存不可变文件内容、完整 Trace/Observation Blob、预览衍生物和 Artifact 内容；本地集成使用 MinIO；
- 单元测试可以使用内存 Fake，但 Fake 必须通过同一 Repository/BlobStore 契约；
- 不实现 JSON/JSONL Repository。Redis 或队列未来只能加速调度、缓存或通知，不能成为唯一事实源。

跨存储写入使用“先对象、后引用”协议：

1. 数据库创建带过期时间的上传意图和服务端生成对象键；
2. 内容写入 Tenant 分区的暂存或内容寻址键；
3. 通过 HEAD、长度和哈希验证对象完整性；
4. 单个数据库事务创建不可变版本/引用并把上传意图标记为已提交；
5. 事务失败时对象保持无引用，由清理器按宽限期删除；上传失败时不创建正式版本。

Artifact 发布优先引用已经提交的 Workspace/Resource 内容，不重复上传。删除先在 PostgreSQL 标记不可见并证明无引用，再异步删除对象；删除失败可重试。任何数据库记录不得指向未经验证或仍在上传中的对象。

## 理由

该方案让 PostgreSQL 成为状态与授权事实源，让对象存储承担擅长的不可变 Blob；补偿协议把不可避免的双写失败收敛为“可回收孤儿对象”，而不是“可见记录指向缺失文件”。

## 影响

### 正面影响

- 条件更新、Lease 和 Rollout 顺序可由数据库保证；
- Blob 可流式处理并使用短期预签名 URL；
- 本地 MinIO 能复现生产对象存储语义。

### 负面影响与成本

- 需要上传意图表、对象校验、补偿任务和孤儿监控；
- 备份恢复必须协调数据库快照和对象版本；
- 集成测试比 JSON 文件测试更重。

### 安全、数据与运维影响

Bucket 默认私有；对象键包含不可伪造的 Tenant 分区但不能代替授权。预签名前必须从 PostgreSQL 重新验证当前调用者。日志不得记录签名 URL、密钥或完整环境变量。

## 验证

- Repository 和 BlobStore 契约同时在内存 Fake、PostgreSQL 和 MinIO 上运行；
- 注入“上传失败、HEAD 失败、事务失败、提交后响应丢失、删除失败”五类故障；
- 证明任何可见 Revision/ResourceVersion/Artifact 都能读到匹配哈希的对象；
- 证明无引用对象经过宽限期可回收，引用不确定时不会删除；
- 跨 Tenant 预览和下载测试必须失败。

## 可逆性与回退

在首个 Schema 迁移前可以调整对象键与上传协议。生产写入后可以替换 S3 厂商，但必须保持 BlobStore 契约并执行复制校验；放弃 PostgreSQL 事实源或不可变对象语义属于高成本迁移。

## 后续工作

- 确定迁移工具、连接池、事务隔离级别和备份策略；
- 定义对象键、哈希算法、上传宽限期和清理指标；
- 为“数据库恢复时间点早于对象存储”编写恢复手册。

## 实施记录

- 开发环境使用已有 PostgreSQL 独立数据库和 MinIO 私有 Bucket；业务表和对象协议尚未实施。
