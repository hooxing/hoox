# 0038 本地 Agent 工作台与公开 API 边界

- 状态：已接受
- 日期：2026-07-28

## 背景

本地开发需要一个可操作的浏览器界面来创建线程和运行、观察事件以及获取产物。浏览器不能读取服务端持久层，也不应保存开发凭据。

## 决策

采用 Vite + React 的单页工作台。开发服务器将 `/api` 同源代理到可配置的 `WEB_API_TARGET`（默认 `127.0.0.1:3001`）。前端 API client 只使用公开 HTTP 契约，并为 POST 自动生成 `Idempotency-Key`；本地固定身份仅在请求 Header 中使用 `Bearer dev-user-a`，界面明确标注该身份且不显示环境变量。

事件和产物端点在后端逐步提供期间保持兼容：列表响应可为数组或 `{ items }`，下载地址可为 `url` 或 `downloadUrl`。运行进行中时以短轮询获取运行、增量事件和产物。

## 影响与验证

工作台无需跨域配置即可连接本地 API。API 异常统一映射为可展示、可判断重试性的错误；事件按 sequence 去重，避免轮询重复渲染。`api.test.ts` 覆盖认证/幂等边界和错误映射，`state.test.ts` 覆盖增量事件合并。

## 可逆性

代理目标、轮询实现和 UI 框架都隔离于 `apps/web`，可在不改变服务端协议的前提下替换。
