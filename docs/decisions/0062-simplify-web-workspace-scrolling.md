# ADR-0062：简化 Web 工作台滚动与交付入口

- 状态：已接受
- 日期：2026-07-31
- 决策者：Runtime 团队
- 关联任务/PR：移除右侧活动栏与可见滚动条
- 替代关系：替代 ADR-0061 中的右侧产物与模型报文抽屉布局

## 背景

右侧活动栏同时展示交付物和模型网络诊断，挤压了主要对话区域；交付物又已经在 Agent 正文后内联展示，因此该栏形成重复入口。固定高度应用壳中的左侧会话列表和中部运行区必须继续独立滚动，但浏览器默认滚动条在当前视觉中较为突出。

## 备选方案

### 方案 A：保留活动栏并仅默认收起

仍能直接查看模型网络诊断，但入口和布局复杂度继续存在，且产物信息重复。

### 方案 B：移除活动栏，保留内联交付；隐藏主要滚动区的滚动条

对话成为唯一主阅读路径。会话列表和运行区仍使用原生滚动，只隐藏滚动条外观，因此鼠标滚轮、触控板、触摸和键盘滚动能力不变。

## 选择与理由

选择方案 B。删除活动栏渲染及会话头部的产物、诊断入口，产物继续通过正文后的内联卡片预览或下载。模型报文读取协议和状态投影不在本次变更中删除，仅不再进入用户工作台。滚动条使用 `scrollbar-width: none` 与 WebKit 伪元素共同隐藏，避免通过 `overflow: hidden` 破坏滚动能力。

## 影响

- 正面：扩大对话空间，减少重复信息和敏感诊断对普通用户的干扰，滚动区域视觉更简洁。
- 负面：工作台不再提供模型网络报文的查看入口；滚动区域边界不再由滚动条提示。
- 兼容：不改变 API、持久化数据、轮询状态或 Artifact 下载与预览契约。
- 安全：减少敏感模型网络报文在普通界面的暴露，不新增网络或宿主机权限。

## 验证

- 组件测试验证会话头部不再出现产物、诊断或活动栏入口，内联 Artifact 入口仍存在。
- 样式测试验证会话列表和运行区仍配置 `overflow-y: auto`，并覆盖 Firefox 与 WebKit 的滚动条隐藏规则。
- 执行 Web typecheck、测试与构建，并尽可能执行全量 `pnpm check`。

## 可逆性

改动仅影响 Web 展示且不迁移数据。若需恢复，可重新挂载活动栏与头部入口并恢复对应样式；服务端诊断协议无需迁移。
