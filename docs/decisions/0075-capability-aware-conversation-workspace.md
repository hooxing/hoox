# ADR-0075：能力感知的对话工作台信息层级

- 状态：已接受
- 日期：2026-08-01
- 决策者：Runtime 团队
- 关联任务/PR：对话工作台体验优化
- 替代关系：细化 ADR-0059、ADR-0061 与 ADR-0062 的展示边界

## 背景

现有 Web 工作台已经具备任务列表、连续对话、运行进度、Artifact 下载、部分媒体预览、停止和归档能力，但页面把运行标识、Sandbox 状态、上下文压缩窗口和原始 MIME 等实现信息放在主要阅读路径中。最终回复与交付文件位于较长运行记录之后，进入已完成任务时也不会稳定定位到最新结果。与此同时，分享、评价、统一文件库、附件和 Office 文档富预览尚无产品能力或服务端契约，界面不能以静态占位伪装这些能力。

## 决策驱动因素

- 让用户优先看见请求、最终回复、当前工作状态和可下载文件；
- 不改变 Thread、Run、Artifact 或连续上下文的服务端事实语义；
- 保留工作记录的透明度，同时避免内部诊断默认占据界面；
- 只呈现已经可完成端到端操作的能力；
- 延续 ADR-0060 的安全 Markdown 边界和 ADR-0062 的单一对话阅读路径。

## 备选方案

### 方案 A：一次性复刻目标产品的全部界面

先呈现分享、评价、附件、文件库和富预览，再逐步补齐能力。视觉完成度高，但按钮无法完成真实操作，会制造错误预期，并迫使前端提前定义尚未评审的协议。

### 方案 B：按现有能力重排信息层级

采用轻量任务栏、紧凑标题栏、窄正文和底部输入区；把进度固定在输入区上方，把最终回复与交付卡片留在主阅读流中；技术记录默认折叠；Artifact 使用可读类型、大小和明确的预览/下载操作。尚未具备的能力不渲染。

### 方案 C：只调整配色

改动最小，但无法解决结果发现困难、进度和正文层级混乱、伪资源链接以及技术字段暴露的问题。

## 选择

选择方案 B。本次只调整 Web 展示和滚动行为：

- 左侧列表定位为紧凑任务导航，不显示开发身份或普通任务时间戳；
- 标题栏不显示 Run ID、上下文窗口等内部字段，仅保留任务状态、对用户有意义的工作区瞬时态和后续任务数；
- 运行进度在输入框上方持续可见，以已完成/总步骤表达进度，工作记录与步骤默认折叠；
- 最终回复之后展示真实 Artifact 卡片，按现有媒体白名单决定是否显示预览，所有已发布文件提供明确下载按钮；
- `resource_version_*` 模型引用不作为站内路由，退化为文本提示，由 Artifact 卡片承担真实下载；
- 会话首次载入或用户仍位于底部附近时自动跟随最新内容；用户主动向上阅读后停止强制跟随；
- 分享、评价、附件、统一文件库和不受支持的富预览继续隐藏。

## 理由

方案 B 能在不增加后端协议和虚假入口的前提下改善主要任务流。它保留连续上下文、Durable Steer、Follow-up、Artifact 和诊断数据投影，只改变默认披露和布局，因此风险集中在可逆的前端层。相比方案 A，它不会把尚未实现的交互承诺给用户；相比方案 C，它直接解决结果发现与交付操作的核心问题。

## 影响

### 正面影响

- 已完成任务打开后更容易看见最新答复与交付文件；
- 运行中可以持续看到当前动作与步骤比例，不需要翻找状态卡；
- 文件格式、大小和操作更易理解，Office 文件不会出现不可用的预览按钮；
- 内部标识、原始 MIME 和工作记录不再抢占主要视觉层级。

### 负面影响与成本

- 任务时间戳和部分连续性诊断不再直接显示在工作台；
- 底部进度区会占用少量固定垂直空间；
- 自动跟随逻辑需要维护“接近底部”这一前端状态。

### 安全、数据与运维影响

- 不修改 API、数据库、对象存储、权限或 Artifact URL 获取方式；
- 减少技术诊断在普通界面的默认披露；
- Markdown 资源引用不再触发本地伪路由，外部链接与危险协议规则保持不变；
- 无数据迁移和新增运维配置。

## 验证

- 组件测试验证进度比例、工作记录默认折叠、用户可读文件元数据和能力感知操作；
- Markdown 测试验证 `resource_version_*` 不生成可导航链接；
- 状态测试验证接近底部时自动跟随、离开底部后停止跟随；
- 样式测试验证 300px 任务栏、810px 阅读区、762px 输入区和进度衔接关系；
- 执行 Web 测试、类型检查、构建以及仓库 `pnpm check`；
- 在桌面与窄屏视口人工检查滚动、下载、预览、停止、归档和 Follow-up。

## 可逆性与回退

改动仅位于 Web 组件、样式和 Markdown 投影，没有数据迁移。可在任意时间恢复原布局、原披露字段和原滚动位置；Artifact 与 Thread 数据无需回滚。若需要重新开放隐藏能力，应先新增并验收相应端到端契约，再独立更新此决策。

## 后续工作

- 分享、评价、附件和统一文件库分别完成产品与协议评审后再进入界面；
- 为 Office 文档富预览定义安全转换或受限渲染方案；
- 根据真实任务长度评估底部进度区展开内容的高度上限。
