# ADR-0085：运行中思考正文的实时披露

- 状态：已接受
- 日期：2026-08-02
- 决策者：Runtime 团队
- 关联任务/PR：Web 运行过程可见性改进
- 替代关系：替代 ADR-0076 中“普通工作台不显示原始思考正文”的 Web 投影结论；恢复并细化 ADR-0072 的披露行为

## 背景

Runtime 已将 Provider 思考流持久化为 `thinking.started`、`thinking.delta` 和
`thinking.completed` 事件，Web 投影也会按顺序聚合正文。但 ADR-0076 为压缩底部状态区，只把思考映射为
“分析任务”轨道项，用户无法得知模型当前实际在分析什么。长任务因此可能在较长时间内只显示抽象状态，
既不利于判断任务是否按预期推进，也无法在结束后回看思考内容。

现有横向工作状态轨道已经承担步骤概览，不能为了恢复正文而退回“思考详情 + 执行步骤详情”两个并列折叠
入口。思考正文仍属于不可信模型输出，必须沿用受限 Markdown 渲染，且流式增量不能让辅助技术持续重复朗读
整个正文。

## 决策驱动因素

- 运行中无需额外操作即可看到持续更新的思考文本；
- 思考结束后恢复紧凑布局，同时允许用户主动回看；
- 保留 ADR-0076 的横向进度轨道及其自动跟随行为；
- 原生键盘交互、展开状态、区域命名和更新状态对辅助技术可理解；
- 不扩大公开事件、持久化、授权或模型输出安全边界。

## 备选方案

### 方案 A：继续只显示“分析任务”轨道项

界面最紧凑，也不会增加正文渲染开销，但无法满足运行中查看真实进展和完成后回看的目标。

### 方案 B：把思考正文作为始终展开的对话消息

正文阅读面积充足，但完成后的长思考会持续挤占对话空间，也会把中间过程与 Agent 最终回复混在同一信息
层级。

### 方案 C：在进度卡中增加单一原生披露区

保留现有轨道作为概览，在其下方增加一个 `details`：思考流活动时自动展开，收到思考终态后自动折叠，
终态下由用户决定是否再次展开。选择此方案。

## 选择

1. Web 继续通过既有 `buildRunProgress` 聚合 `thinking.delta`，在横向进度轨道下呈现安全 Markdown 正文；
   不展示 Provider 签名、调用标识或其他内部事件字段。
2. 仅当思考状态和 Run 状态都为 `running` 时显示“正在思考”并默认展开。收到
   `thinking.completed` 后显示“思考已完成”并自动折叠；Run 已失败、取消或先行进入其他终态而思考事件未
   收敛时，显示“思考已结束”，轨道也不得继续显示运行中动画。
3. 披露区使用原生 `details/summary`。摘要与正文区域通过 `aria-controls`、`aria-labelledby` 关联；正文是
   可聚焦、限高且可滚动的 region，并以 `aria-busy` 表达流式状态。正文显式关闭 live announcement，避免
   每个增量触发重复朗读；“正在思考 / 思考已完成 / 思考已结束”状态使用 polite announcement。
4. 活动正文默认跟随最新内容；用户向上滚动离开底部后停止抢夺滚动位置。完成后用户手工展开或折叠的
   选择在同一状态的后续渲染中保持不变，下一段实时思考开始时再自动展开。
5. 横向工作状态轨道、步骤压缩、横向滚动和自动定位末项的实现保持不变；不恢复已删除的执行步骤折叠区。

## 理由

方案 C 同时提供“概览”和“当前细节”两种粒度，运行中无需点击，结束后只保留一行可回看的状态。原生
披露控件比自定义按钮加隐藏面板具有更稳定的键盘和展开语义。对增量正文关闭 live announcement，而只
播报低频状态变化，可以避免屏幕阅读器在 100ms 合并周期下被大量文字淹没；可聚焦正文仍允许用户按需
读取和滚动。

## 影响

### 正面影响

- 用户可以实时确认 Agent 的分析方向，并在完成后按需回看；
- 完成态默认紧凑，现有步骤轨道仍可快速扫读；
- 思考事件未正常收敛时不会在终态 Run 上留下“正在思考”的误导状态；
- 键盘用户和辅助技术可以识别披露状态、正文区域及流式忙碌状态。

### 负面影响与成本

- 活动时底部进度卡会增高，窄屏可用高度减少，因此正文必须限高滚动；
- 增量到达时会重新渲染当前完整 Markdown，超长思考比只显示轨道有更高的前端开销；
- 思考正文可能包含模型的中间错误判断，用户需要结合最终回复理解。

### 安全、数据与运维影响

- 不修改 API、数据库、事件、保留期或 Tenant/Thread/Run 授权；
- 正文继续使用禁用原始 HTML、外链图片和危险 URL 的 `AssistantMarkdown`；
- 不新增配置、依赖、迁移或运维步骤。

## 验证

- Web 组件测试验证活动思考默认展开并展示增量正文，完成态默认折叠且可以手工展开；
- Web 组件测试验证 Run 异常终态关闭活动状态，并验证摘要、region、关联 ID、`aria-busy` 与 live 策略；
- 样式测试验证横向轨道仍可滚动，且只有一个限高、可滚动、可聚焦的思考披露区；
- 执行 Web 测试、类型检查、构建以及仓库 `pnpm check`。

## 可逆性与回退

改动只位于 Web 投影、组件和样式层，没有数据迁移。可删除思考披露区并恢复 ADR-0076 的轨道-only
展示；已经持久化的思考事件、Thread History 与授权边界无需回退。
