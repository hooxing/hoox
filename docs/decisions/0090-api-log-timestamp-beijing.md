# ADR-0090：API 日志时间使用东八区可读时间

## 背景

API 当前使用 Fastify/Pino 默认的 Unix 毫秒时间戳。该格式适合机器处理，但本地排查日志时不直观；开发环境主要在中国东八区使用。

## 决策

API 的 Pino `time` 字段改为固定东八区的 ISO-8601 字符串，例如 `2026-08-03T08:00:00.123+08:00`。格式化显式指定 `Asia/Shanghai` 和 `+08:00`，不读取宿主机时区设置。

## 影响

- 新日志更适合人工阅读和按时间排序。
- `time` 字段的数据类型从数字变为带偏移量的字符串；日志消费者若依赖 Unix 毫秒值，需要改为解析 ISO-8601 时间。
- 领域数据、数据库时间和 API 协议中的 UTC 时间语义不变；本决策只作用于日志展示。

## 验证与可逆性

通过 API 日志格式化单元测试和 API 构建验证。恢复 Pino 默认 `timestamp` 配置即可回退。
