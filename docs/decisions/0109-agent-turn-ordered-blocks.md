# ADR-0109：Agent 回合采用有序内容块投影

## 背景

运行事件包含多段思考、模型正文和工具调用。旧页面分别合并全部思考与全部正文，并把持久化的每条 assistant 消息渲染成独立头像，既丢失过程顺序，也容易让用户误认为一次任务由多个 Agent 分别回答。

## 决策

- 以一次 Run 作为一个 Agent 回合，头像和名称只属于回合。
- 前端按事件顺序投影 `thinking`、`answer` 和 `tool` 内容块。
- 思考块无论运行中还是完成后均默认折叠。
- 工具块通过 `callId` 原位更新状态；类型由工具名归类，标题只接受服务端显式提供的安全 `presentation.title`，不解析原始参数。
- 交付物继续归属于整个 Run，并位于回合内容之后。

## 影响

用户可以按真实顺序阅读“思考—回答—工具—回答”，同时不会看到重复头像。未提供安全展示标题的工具只展示动作类别，避免泄露命令、路径或其他调用参数。该投影仅影响 Web 展示，可通过恢复旧投影组件回滚。

## 验证

通过 Web 单元测试覆盖顺序投影、工具状态原位更新、思考默认折叠和单回合头像，并执行格式、类型及测试检查。
