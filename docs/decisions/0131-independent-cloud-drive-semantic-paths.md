# ADR-0131：独立云盘入口、语义路径与无文本文件选择

- 状态：已接受（试验分支）
- 日期：2026-08-08
- 决策者：Runtime 团队
- 关联任务/PR：`test/cloud-drive-history-files`
- 关联决策：ADR-0119、ADR-0129、ADR-0130

## 背景

ADR-0130 首版把云盘作为技能中心标签，并在输入框选择历史文件后同时保留附件 Chip 与可见的
`@文件名` 文本。历史目录和文件入口还包含秒级时间前缀。实际界面验证表明，这三个选择增加了用户理解成本：
云盘是个人文件能力而不是技能管理能力；附件 Chip 已经足以表达选择结果；时间可以作为分组和元数据展示，不需要进入面向人浏览的目录名。

同时，Agent 的授权身份从来不是界面文本，而是 `resourceId + versionId` 结构化附件。Worker 会在最新 user turn
中注入稳定的 Sandbox `/resources/<resourceId>/<versionId>/<name>` 路径，因此删除输入框中的
`@文件名` 不会降低 Agent 的文件可用性，也不会改变 Prompt 缓存边界。

## 决策

1. 云盘从技能中心移出，在侧栏“技能中心”下方作为独立同级入口；技能中心只管理技能，云盘使用独立对话框。
2. 新生成的个人历史目录直接使用语义 Thread 标题，新文件入口直接使用 Resource 原名，不再添加时间前缀。
3. 重名目录仅在冲突时追加 `-2`、`-3`；重名文件把序号放在扩展名前，例如
   `采购合同-2.docx`。数据库时间字段继续用于月份分组、排序、分页和审计。
4. 迁移 `0039_semantic_history_filesystem_names` 将已有 personal Tenant 的 ready/fallback 目录与文件入口改为语义名称。
   迁移先写入唯一临时名，再按稳定时间与身份排序分配冲突序号，避免唯一约束下的交换冲突；down 使用保留的时间元数据恢复旧格式。
5. 输入框末尾的 `@查询` 只负责打开和过滤候选列表。候选列表默认选中第一项，支持上下键循环移动，Enter 确认，鼠标悬停同步当前项。
6. 选择完成后移除输入框中的 `@查询`，只显示可移除的文件 Chip；Chip 和候选列表展示 Resource 原名，不展示技术性 `@` 前缀。
7. 提交协议保持不变：Web 发送结构化附件，未输入任务文字时使用既有“请处理本轮提供的文件。”占位请求；
   Runtime 只在最新 user turn 注入文件名和 Sandbox 路径。System、developer/harness Prompt 与工具 Schema 不增加动态内容。
8. `/resources` 稳定路径不受历史目录重命名影响。迁移会改变旧的 `/history` 和 `/thread-files` 可读别名；
   这些路径属于发现视图而非持久附件身份，正在执行的附件仍通过 `/resources` 访问。

## 影响

### 正面影响

- 云盘和技能中心的产品边界清晰，侧栏可以独立演进两种能力；
- 用户选择文件后不会在任务文本中看到重复文件名，发送内容更简洁；
- 键盘可以完成候选导航和确认；
- 历史目录更接近本地云盘，时间仍可通过月份、日期副标题和排序获得；
- Agent 继续获得稳定的 Sandbox 路径，授权、按需读取和上下文缓存策略不变。

### 成本与限制

- 去掉时间后重名概率提高，需要持久化冲突序号；
- 迁移后，曾由 Agent 自行记录的旧 `/history` 或 `/thread-files` 别名可能失效；
- 当前标题变更仍不会自动重命名已就绪目录，动态标题同步与旧路径兼容别名继续作为后续能力；
- 候选列表当前最多八项，键盘导航不替代云盘中的完整搜索和分页。

## 验证

- Web 测试覆盖侧栏独立入口、技能中心不再包含云盘、独立云盘关闭行为；
- Composer 测试覆盖上下键、Enter、删除 `@查询`、只显示文件 Chip；
- 主流程测试确认提交文本不包含文件名且仍发送同一结构化附件；
- Resource 测试覆盖无时间语义名称以及目录、文件冲突格式；
- 迁移测试覆盖 personal Tenant、稳定冲突分配、扩展名前序号和可逆时间命名。

## 可逆性

前端入口和选择交互可独立回退。数据库迁移 down 可利用未删除的
`directory_timestamp`、`directory_time_zone` 与 `first_attached_at` 恢复时间前缀。
结构化附件、ResourceVersion、Stable Blob 与 `/resources` 路径不随本决策回退。
