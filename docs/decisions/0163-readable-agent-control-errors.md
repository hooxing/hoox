# ADR-0163：子 Agent 控制错误分离机器码与可读说明

## 背景

子 Agent 控制面此前直接把内部异常文本同时作为 `code` 和 `message`。例如目标空闲时返回 `AGENT_NOT_RUNNING/AGENT_NOT_RUNNING`，目标不存在时返回 `AGENT_NOT_FOUND/AGENT_NOT_FOUND`。父 Agent 虽能读取开发者机器码，但无法得到纠正建议，也无法可靠区分已知状态错误与未知平台故障。

直接向模型透传未知异常文本还可能暴露数据库、Provider 或部署细节。

## 决策

新增稳定错误投影表：

- 已知、可纠正的控制错误保留原机器码，并返回固定中文说明与建议；
- `AGENT_NOT_FOUND`、`AGENT_NOT_RUNNING`、`AGENT_BUSY`、参数错误、容量错误等均显式投影；
- 未知异常统一投影为 `AGENT_CONTROL_FAILED`，使用不包含内部细节的稳定消息；
- `code` 供程序判断，`message` 供父 Agent 理解和修正，不再重复。

## 影响

- 父 Agent 可区分目标错误、状态错误、参数错误与未知平台故障。
- 未知内部异常文本不再进入模型可见工具结果。
- 既有稳定机器码保持兼容。

## 验证

单元测试覆盖已知错误的机器码与可读说明，以及未知异常的脱敏统一投影。

## 可逆性

可恢复直接透传异常文本，但会重新降低可纠正性并增加内部信息泄漏风险。
