# ADR-0170：以普通 Thread/Run 接入 GAIA 原生能力评测

- 状态：已接受
- 日期：2026-08-13

## 背景

项目需要了解当前 Runtime 在既有模型、工具、Sandbox 和远端依赖下的实际能力，而不是严格复现 GAIA 官方排行榜环境。评测任务需要归属现有角色、关闭长期记忆并保留普通任务记录。GAIA 完整数据和标准答案受访问条件约束，公开课程服务只提供一组 Level 1 题目及附件。

## 备选

1. 直接接入 GAIA 官方 Harness，补齐官方模型、浏览器和评分配置。结果更适合横向排名，但会改变当前 Runtime 配置，也需要受限数据权限。
2. 在测试代码中模拟题目和工具。执行稳定且便宜，但无法反映真实模型、网络、Sandbox 和附件链路能力。
3. 增加外置适配脚本，把公开题目按普通用户输入送入现有 API，记录回答和运行诊断，不提交外部排行榜。

## 决策

采用方案 3。评测器不进入 Runtime 应用装配，不修改工具 Schema 或提示词；每道题建立一个普通 Thread/Run，附件复用资源上传接口。API、Worker 和评测器都由启动环境显式关闭记忆，脚本同时对自身环境执行失败关闭校验。当前入口不保存标准答案、不实现近似评分，也不调用会产生外部状态的提交接口。

## 影响

- 能直接观察当前 Runtime 的端到端完成情况、回答、工具使用和失败语义。
- 任务保存在当前角色下，可由现有界面复查。
- Run 成功率只表示执行链路结束，不等于答案正确率；没有答案权限时必须人工审阅。
- 公开题目服务发生变更或不可用时，评测会明确失败，不回退到内置题目副本。
- 评测结果可能包含题目回答，只写入被 Git 忽略的 `.tmp`，不得提交。

## 验证

- 单元测试覆盖参数边界、题目选择、答案提取和记忆失败关闭。
- 使用远端映射的 PG、CubeSandbox、MinIO 启动本地 API/Worker，运行三个公开样本并检查生成报告与持久 Thread。
- 执行格式、lint、根类型检查和定向测试。

## 可逆性

脚本、文档和 package 命令可以直接删除，不涉及数据库 Schema 或生产运行时行为。已经创建的评测 Thread 属于普通持久数据，不随代码回退自动删除；根据本决策默认保留。
