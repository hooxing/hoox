# ADR-20260816114151：将用户面对的 Agent 产品命名为 Hoox

## 状态

已替代，2026-08-18 由 ADR-20260818144124 替代。本决策细化 ADR-20260816002622 的品牌边界，不回退已经完成的技术项目身份迁移。

## 背景

AISay Runtime 已作为仓库、第一方包、部署身份和供应链属性的统一技术名称。实际页面验证后，`AISay` 作为用户面对的 Agent 名称辨识度不足；同时 `aisay.cc` 更适合作为组织域名，由具体产品使用子域名承载。

## 备选方案

### 方案 A：页面和 Agent 继续使用 AISay

技术身份最统一，但产品名与组织、底座名称重叠，页面个性和后续产品扩展空间不足。

### 方案 B：把仓库和包命名空间再次整体迁移为 Hoox

所有层级使用同一名称，但会在刚完成 `@aisay/*` 迁移后再次制造大范围破坏性改名，也混淆产品与技术底座。

### 方案 C：产品与底座分层

保留 AISay Runtime 作为开源技术底座，把用户面对的 Agent 产品命名为 Hoox，并以 `hoox.aisay.cc` 作为计划公开入口。

## 选择

采用方案 C，并规定：

1. 主工作台浏览器标题、侧边栏品牌、Agent 消息身份和用户任务文案统一使用 **Hoox**。
2. 产品宣传语固定为“你说，它做。”，在工作台品牌区和项目 README 中展示。
3. Hoox 的计划公开入口为 `hoox.aisay.cc`；本仓库的配置示例继续使用明显的无效占位域名，真实部署地址由环境注入。
4. 固定 Platform Harness 明确模型身份为 Hoox，同时保留 AISay Runtime 的托管和安全边界；Prompt 版本从 `runtime-system-prompt.v11` 推进到 `runtime-system-prompt.v12`。
5. 根包 `aisay-runtime`、第一方 scope `@aisay/*`、JWT audience、Compose、SBOM、数据库应用名和内部管理/轨迹页面继续使用 AISay Runtime 技术身份。

## 影响

- 用户在页面和模型回答中看到的 Agent 名称由 AISay/Agent 变为 Hoox。
- 技术部署和依赖方无需再次迁移包名或配置身份。
- 已经生成的历史消息正文和 Thread 标题不做数据改写。
- 公开域名上线时仍需单独完成 DNS、TLS、反向代理、CORS 和生产身份配置。

## 验证

- 更新工作台测试，固定 Hoox、`H` 标记和宣传语。
- 更新 Prompt 快照，固定 Hoox 身份与 `runtime-system-prompt.v12`。
- 扩展项目身份契约，验证 `hoox.aisay.cc` 和产品/底座分层。
- 在本地工作台热更新后检查页面标题、可见文本、业务请求与浏览器控制台。

## 可逆性

本次只修改用户品牌、Prompt 固定字节和文档。公开前可用单个提交回退；上线后回退还需要同步站点域名、页面缓存和 Prompt 版本策略，但不涉及数据库结构或包命名空间。
