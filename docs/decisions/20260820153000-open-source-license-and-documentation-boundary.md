# ADR-20260820153000：项目采用 Apache License 2.0 并建立公开文档分层

- 状态：已接受
- 日期：2026-08-20
- 决策者：Hoox 项目维护者
- 关联任务：开源规范与文档整理
- 替代：无
- 被替代：无

## 背景

Hoox 已具备较严格的测试、生产 Gate、SBOM、第三方许可证和来源证据，但仓库缺少项目级开源许可证、贡献与安全入口。根 README 同时承载产品介绍、API 细节、内部诊断、生产 Gate 和首次开发配置，外部读者难以快速理解项目、运行最小链路或判断文档权威性。

仓库已有两百余份 Markdown，其中绝大多数是 ADR。历史决策数量丰富，但当前架构、仓库地图、配置、命令和生产就绪边界缺少独立入口。部分实施计划和原型参考与当前文档混放，ADR 编号规则也在四位递增编号与北京时间时间戳之间冲突。

## 约束

- 本次不修改 Runtime 代码、协议、数据库 Schema 和部署行为。
- 有用的技术细节必须迁移到对应主题文档，不能因缩短 README 而丢失。
- 第三方源码和受限开发素材继续适用自己的许可证。
- 开源许可证应允许个人与企业使用、修改和分发，并提供明确专利授权。
- 历史 ADR 路径不能为追求编号整齐而破坏已有引用。
- 当前项目主要维护语言为中文。

## 备选方案

### 方案 A：MIT License

文本简短、认知成本低、商业使用友好，但专利授权和专利终止条款不如 Apache License 2.0 明确。

### 方案 B：Apache License 2.0

允许使用、修改和分发，提供明确专利授权与 NOTICE 机制，适合包含 Runtime、Provider、企业部署和 vendored Apache 组件的基础设施项目；代价是许可证文本和合规要求比 MIT 更长。

### 方案 C：AGPL 系列许可证

可以要求网络服务修改公开源码，有利于限制闭源托管分叉，但会提高企业采用、集成和贡献门槛，也可能与项目未来商业策略和部分依赖审查产生额外复杂度。

### 暂不声明许可证

可以避免立即作出法律选择，但公开仓库在没有许可证时不构成可合法复用的开源项目，与本次目标直接冲突。

## 决策

1. Hoox 项目级源码与文档采用 Apache License 2.0。
2. 第三方组件、vendored 源码和受限开发素材继续由 `THIRD_PARTY_NOTICES.md` 及对应目录许可证控制，不因根许可证而改变。
3. 根 README 只保留项目定位、能力、成熟度、最短启动路径、架构摘要和文档导航。
4. 当前说明按架构、参考、开发、运维和维护者诊断分层；实施计划进入 `docs/plans`，历史原型进入 `docs/archive`。
5. ADR README 只保存规则和导航，完整历史目录独立到 `catalog.md`。
6. 新 ADR 使用北京时间时间戳；历史四位编号及重复编号不改名。
7. 增加贡献、安全、行为准则、支持、Issue 模板和 PR 模板。

## 理由

Apache License 2.0 在宽松采用和明确专利授权之间提供合适平衡，适合 Agent Runtime、Provider 与基础设施集成场景。文档分层让用户不必阅读内部 Gate 和数百份 ADR 才能理解项目，同时保留维护者需要的失败语义、生产约束和历史证据。

## 影响

### 正面影响

- 仓库具备明确项目级开源授权。
- README 更适合作为公开项目首页。
- 用户、贡献者和维护者拥有不同阅读入口。
- 当前说明、决策历史和实施计划的权威关系更清晰。
- Issue 与 PR 提交包含安全、验证和兼容性检查。

### 负面影响

- 文档移动会改变部分相对链接，需要一次性检查和维护。
- 中文为主会限制部分国际贡献者，后续若决定双语需要新的维护策略。
- Apache License 2.0 的 NOTICE 和第三方合规要求需要持续维护。

### 安全与隐私

安全策略明确要求私下报告跨租户、凭据、沙箱和供应链问题；公开模板禁止上传诊断正文、签名 URL、对象键、内部地址和用户数据。

### 数据、兼容与迁移

不改变运行时数据、API 和数据库。仅文档路径和项目授权发生变化。

### 运维与可观测性

生产 Gate 和诊断细节从根 README 移入专门文档，内容继续保留并明确静态证据不能替代真实 readiness。

## 验证

- 检查 Git diff 只包含 Markdown、许可证和 GitHub 社区模板。
- 执行 Markdown 格式检查。
- 扫描所有 Markdown 相对链接和本地锚点。
- 检查 README 引用的命令、端口、脚本和路径存在。
- 检查 ADR 目录无新增四位编号，目录包含本记录。

## 可逆性

文档移动和 README 可以通过 Git 回退。许可证一旦被公开版本采用，已经获得该版本副本的使用者仍保留该版本授予的权利，因此许可证选择对已发布提交不可完全撤销；未来可以对新版本采用不同许可，但必须进行独立法律和兼容性评估。
