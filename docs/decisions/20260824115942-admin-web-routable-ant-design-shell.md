# 后台管理 Web 采用可路由的 Ant Design 应用外壳

- 状态：部分已替代（运行配置导航与管理工作流；剩余有效范围见替代关系）
- 日期：2026-08-24
- 决策者：Runtime 维护者
- 关联任务/PR：重构后台管理界面与导航
- 替代关系：扩展 ADR-20260821004057 的信息架构呈现；模型配置交互被 ADR-20260825180549 部分替代，应用外壳、运营、用户治理和权限边界继续有效

- 被部分替代：[ADR-20260906195752](20260906195752-admin-task-oriented-configuration-and-publication.md)。运行配置导航、模型/记忆多步操作与 Skill 审批页面由新决策替代；应用外壳、路由、缓存及服务端授权边界继续有效。

## 背景

`admin-web` 已经覆盖工作台、运营统计、用户治理、模型、记忆、Skills 和运行配置，但页面使用组件内状态切换模块，
无法复制模块地址、使用浏览器前进后退或在刷新后保留位置。全部基础控件和应用外壳由本地 CSS 分别实现，导航、反馈、
窄屏适配和页面密度缺少统一设计约束。

管理动作并非普通 CRUD：模型与记忆需要创建草稿、探测和发布，Skill 需要提交、审核、发布和撤销。前端还必须保留
同源身份网关注入管理身份、服务端授权和服务端不可变审计等安全边界，不能为了套用后台框架改写管理协议。

## 备选方案

### 方案 A：整体迁入 Ant Design Pro

Ant Design Pro 提供完整后台脚手架，但会把现有 Vite 应用迁移到 Umi Max，同时改变构建、路由、请求和测试装配。
界面收益不足以证明这次应用框架迁移，故不采用。

### 方案 B：使用 Refine 或 React Admin

两者能快速生成资源列表和 CRUD 表单，但当前主要动作是领域命令和版本状态流。把 API 伪装成通用 Resource 会增加适配层，
前端生成审计也与服务端不可变事实冲突，故不采用。

### 方案 C：保留 Vite，组合成熟的窄层库

使用 Ant Design 统一视觉与交互，React Router 提供模块地址，TanStack Query 负责请求去重、缓存失效和重新获取；现有
类型化 API Client 继续拥有协议适配，页面继续显式表达领域工作流。

## 选择

采用方案 C，并固定以下边界：

1. `admin-web` 保留 React 19、Vite、TypeScript 和 Vitest，引入精确版本的 Ant Design 6、React Router 7 与
   TanStack Query 5；不引入 Umi、Refine、React Admin、Tailwind 或新的全局状态库。
2. 管理模块使用浏览器路径，应用外壳按“工作台、运营、AI 能力、系统”分组展示；直接访问未知路径回到工作台。测试和
   注入式嵌入场景使用内存路由，不修改全局浏览器地址。
3. Ant Design 只负责通用设计系统和外壳。模型目录、Revision、Skill 状态流和用户停用等领域界面继续由本仓库组件表达，
   不把它们转换成通用 CRUD。
4. TanStack Query 包装控制面读取并在管理动作成功后失效控制面缓存。管理协议仍由现有 API Client 适配，组件不能自行
   拼接新的身份头或回显部署秘密。
5. 前端显示的角色和权限状态只用于说明及交互收敛；授权继续由 `admin-control-api` 执行。操作审计页只读取服务端事实，
   浏览器不创建权威审计记录。
6. 后台服务或 PostgreSQL 不可用时保留原有失败关闭和离线说明，不能用示例数字或假健康状态填充页面。

## 理由

该组合复用成熟组件和服务器状态管理，又不要求改变已有领域协议、部署方式或安全边界。可路由导航改善日常定位和协作，
统一主题、响应式侧栏和反馈组件解决界面一致性问题；各库职责窄，未来可以独立替换而不重写管理 API。

## 影响

- 后台静态包增加 Ant Design、图标、React Router 和 TanStack Query 依赖及体积；
- 模块名称和分组改为业务语义，新增独立操作审计入口；
- 页面刷新和浏览器前进后退会保留当前模块；
- 控制面请求通过 Query Client 去重和失效，现有迟到响应保护继续保留；
- API、数据库权限、配置 Revision、Run 快照和审计写入语义不变。

## 验证

- Web 测试覆盖分组菜单、模块切换、配置和用户原有工作流以及独立审计入口；
- 类型检查和生产构建验证 React 19、Vite 与新增依赖兼容；
- 浏览器检查覆盖桌面、折叠侧栏、窄屏和后台离线页面；
- 现有 API Client 测试继续覆盖同源凭据、幂等键和失败映射。

## 可逆性与回退

回退只需恢复旧应用外壳和组件内模块状态，并移除四个前端依赖；管理 API、数据库和持久化事实不需要迁移。已经存在的
配置版本和审计记录不依赖新的前端路由，可以继续由旧页面读取。
