# 后台模型用量指标与开发轨迹入口边界

- 状态：部分已替代（Demo 轨迹入口）
- 日期：2026-08-24
- 决策者：Runtime 维护者
- 关联决策：补充 ADR-20260815232211 与 ADR-20260821004057；受控 Demo 的同源轨迹入口由 [ADR-20260903152652](20260903152652-demo-trajectory-default-deployment.md) 替代，低敏感模型用量聚合边界继续有效

## 背景

数据运营页已经通过受限 PostgreSQL 聚合视图展示用户、对话和运行可靠性，但无法观察模型吞吐、缓存利用和 Token
用量。内部轨迹投影已经定义这些指标的计算公式，不过轨迹数据可能包含完整 Prompt、思考、工具参数和模型报文，且只在
development 开关启用时写入本地不可变镜像。让生产后台扫描该目录或嵌入完整查看器，会把敏感诊断能力误作运营数据源。

## 备选方案

### 方案 A：后台直接嵌入内部轨迹查看器并从轨迹文件计算指标

开发量小，但生产 Worker 不创建本地镜像，关闭诊断后指标立即消失；完整轨迹也缺少生产管理身份、脱敏、审计和保留边界。

### 方案 B：只展示 Provider 临时返回值，不持久化用量

不会新增数据事实，但刷新后无法得到平台级 24 小时聚合，进程重启和多 Worker 也会导致统计漂移。

### 方案 C：持久化低敏感用量观测，后台只读取受限聚合；轨迹保持独立开发入口

Worker 在每次 Assistant 生成完成后保存固定数值，后台按 24 小时聚合。开发管理页可以新窗口打开回环轨迹查看器，但不
代理、嵌入或读取轨迹正文。

## 选择

采用方案 C，并固定以下语义：

1. Worker 从 Pi 原始 `message_start` 与 `message_end` 边界观察用量；观测只包含未缓存输入 Token、输出 Token、缓存读取
   Token 和本地单调时钟生成时长，不保存 Provider/模型身份、Prompt、响应、思考、工具参数、密钥或错误正文。
2. 同一次模型调用的四项数值在一个租户事务中原子写入既有低基数指标表，并用 Attempt、Agent namespace 和模型调用序号
   组成幂等观测身份。指标失败不改变已经完成的 Run 业务结果。
3. 后台受限聚合视图只统计最近 24 小时样本。`inputTokens = inputTokensUncached + cacheReadTokens`；
   `outputTokensPerSecond = outputTokens / (generationDurationMs / 1000)`；
   `cacheHitRate = cacheReadTokens / inputTokens`。分母为零时对应比例返回 `null`，页面显示未知而不是伪造零。
4. 吞吐量使用聚合输出量除以聚合生成时长，不平均每次调用的速率，避免短调用被赋予过高权重。生成时长仍是
   Assistant 流边界，不等于完整 Provider 请求延迟或首 Token 延迟。
5. `admin-web` 只在 Vite development 构建中显示 `http://127.0.0.1:4188` 的新窗口链接。生产构建不显示入口；任何环境都
   不使用 iframe、反向代理或 Admin API 转发轨迹内容。

## 理由

数值观测可以在关闭敏感诊断时持续工作，也能跨 Worker 和进程重启稳定聚合。复用低基数、租户隔离、只追加的指标账本
避免新增一套内容型遥测系统；原子写入保证缓存率和吞吐量不会读取到半组事实。完整轨迹继续保持独立回环工具，使运营入口
和维护者诊断入口各自拥有与敏感度匹配的权限边界。

## 影响

- 后台统计协议新增 `modelUsage24h`，Admin API 与 Web 必须同步部署；
- PostgreSQL 迁移扩展固定指标名白名单和 `admin_runtime_statistics`，已有业务表及轨迹格式不变；
- 新部署完成但尚无模型调用时，Token 总量为零，吞吐和缓存率显示未知；
- 指标属于运营观测，不是 Provider 账单真源，也不包含 TTFT、请求排队或网络往返时长；
- development 维护者仍需单独启动轨迹查看器，链接不保证目标服务已经运行。

## 验证

- Worker 测试覆盖真实 Faux Provider 事件到低敏感用量端口的投影，并断言观测不包含请求或响应；
- 持久化测试覆盖整数 Token、有限时长和迁移固定白名单，down 在已有模型用量事实时失败关闭；
- 协议测试覆盖完整样本与无样本的 `null` 比例；
- Web 测试覆盖四项指标、公式文案、development 新窗口链接和不存在 iframe；
- 受影响包的类型检查、测试、格式、Lint、构建和 PostgreSQL 迁移验证通过后提交。

## 可逆性

没有模型用量观测时可以执行 down migration，恢复旧指标白名单和后台统计视图。已有观测后 down 失败关闭，避免静默删除
统计语义；需要回退应用时可先停止新写入并保留新列兼容读取。轨迹链接可以独立移除，不影响本地镜像和查看器。
