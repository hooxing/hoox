# ADR-20260901114930：手工几何重建品牌矢量候选

- 状态：提议
- 日期：2026-09-01
- 决策者：Hoox 维护者
- 关联 Issue / PR：无
- 替代：无
- 被替代：无

## 背景

[固定品牌栅格衍生资产与入口尺寸](20260901110046-raster-brand-derivative-contract.md)
在没有矢量真源时补齐了透明、单色和固定尺寸 PNG，同时明确禁止把未经几何复核的自动描摹结果
声明为真源。现有四个 RGB PNG 足以测量双钩、字标、颜色和画布关系，但不能无损缩放，也不适合
在任意背景上作为正式矢量接口。

当前需要先提供可直接审阅的 SVG，确认几何重建方向，再决定是否切换 Web、Admin Web、README
或外部材料的引用。

## 约束

- 安全与租户边界：文件只包含静态品牌几何，不包含用户、租户、环境或生产数据。
- 数据与迁移：不涉及数据库、对象存储或运行时数据迁移。
- 兼容性：四个原始 PNG、十二个栅格衍生物及其现有引用必须保持不变。
- 运维与故障恢复：矢量候选未通过品牌复核时，应用继续使用已验证 PNG。
- 性能与成本：SVG 必须由少量可维护路径组成，不得嵌入高分辨率 PNG、字体或脚本。
- 交付范围与时间：本切片只生产审阅候选和结构契约，不授权切换产品引用。

## 备选方案

### 方案 A：按图形不变量手工重建路径

测量现有 PNG 的画布、轮廓和负空间，以一个可复用双钩路径、两个同规格椭圆环和三个断开的 `X`
路径重建 SVG。优点是节点少、可编辑、可无损缩放；代价是仍需要品牌方做最终几何验收。

### 方案 B：自动描摹 PNG

能够快速得到轮廓，但会把抗锯齿、轻微纹理和背景污染转换成大量节点，无法证明两侧线宽、圆角、
相向开口和断笔关系稳定，不适合作为品牌真源。

### 暂不实现

继续只保留 PNG 能维持当前界面，但无法提供可审阅的矢量候选，也会推迟后续无损缩放和自定义背景
场景。

## 决策

提议采用方案 A，并先提交四个不被应用引用的审阅候选：彩色独立标志、彩色横版、纯白反向横版和
碳黑单色独立标志。路径采用 `#19191A` 与 `#177654` 品牌色；两个 `O` 使用相同内外椭圆并保持
水平开口相向；`X` 的副笔画拆成上下两个独立路径，不用背景色覆盖完整笔画模拟断口。

品牌方接受候选前，本 ADR 保持“提议”，SVG 不承担正式真源或应用静态接口职责。接受时应更新本
ADR 状态、当前品牌参考和消费方契约；如需调整几何，直接修改候选及其结构测试，不覆盖任何 PNG。

## 理由

手工重建能把已知图形不变量显式编码为少量几何关系，并避免自动描摹噪声。先保持消费方不变，可让
视觉复核与产品 UI 重构解耦；候选不符合品牌预期时，回退不会影响当前 favicon、PWA、README 或
应用侧栏。

## 影响

### 正面影响

- 获得可任意缩放、可检查节点和颜色的真实矢量候选。
- 原始和衍生 PNG 全部保留，现有产品表面不发生视觉切换。
- 结构测试能够阻止 SVG 回退成栅格嵌入、字体依赖或复杂自动描摹。

### 负面影响

- 仓库暂时同时保存 PNG 与尚未被消费的 SVG。
- 像素轮廓接近不能替代品牌方对曲线、字标和小尺寸表现的人工接受。

### 安全与隐私

- SVG 不包含外部 URL、脚本、`foreignObject`、字体或栅格数据。

### 数据、兼容与迁移

- 不修改或删除任何现有路径；应用、manifest 和 HTML 不切换引用。
- 候选被接受后，既有 PNG 仍需作为兼容接口保留，删除策略另行决定。

### 运维与可观测性

- CI 读取 SVG 文本并验证画布、路径节点上限、禁止元素和品牌颜色。
- 浏览器渲染与 PNG Alpha 轮廓对比属于接受证据，不成为生产运行时依赖。

## 验证

- `tests/brand-assets.test.ts` 验证四个文件存在、画布稳定、包含路径、节点数量有界，且不含栅格、
  字体、脚本、外部 URL 或可视文字元素。
- Chromium 在原画布尺寸渲染彩色独立标志和横版候选；横版二值轮廓与透明 PNG 的交并比为
  `0.9198`，源轮廓覆盖率为 `0.9797`。字标局部交并比为 `0.9354`，其中 `H` 为 `0.9657`、
  `X` 为 `0.9627`。
- 人工检查纸白与深色背景上的双钩负空间、两个 `O` 的水平相向开口和 `X` 真实断笔；16–32px
  小尺寸验收仍待品牌方确认。

## 可逆性

在应用引用切换前，可以删除四个 SVG 及其候选契约而不影响任何现有产品入口。接受并公开引用后，
SVG 文件名应按静态兼容接口保留；几何调整需要版本化评审，不能原地破坏外部缓存预期。
