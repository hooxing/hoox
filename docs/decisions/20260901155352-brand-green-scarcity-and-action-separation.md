# ADR-20260901155352：品牌绿稀缺使用并与操作语义解耦

- 状态：已接受
- 日期：2026-09-01
- 决策者：Hoox 维护者
- 关联 Issue / PR：无
- 替代：[ADR-20260901104943](20260901104943-shared-ui-theme-token-boundary.md) 中品牌色可直接映射通用操作的实现假设；不替代共享主题包与渐进迁移边界
- 被替代：无

## 背景

首个 UI Token 切片将翡翠绿 `#177654` 同时用于品牌、主要操作、选中态和键盘焦点。该映射满足
静态对比度，但在真实工作台中让同一高识别度颜色反复出现在按钮、导航、会话选择和空状态，削弱了
Logo 的记忆点，也让品牌与成功状态过于接近。

现有 Web 外壳在主题迁移前已经使用深灰绿 `#344D42` 表示主要操作、暖中性色表示页面结构；这组
颜色更适合高频交互。品牌绿仍应保留，但用途应类似产品签名，而不是成为全部功能状态的默认颜色。

## 约束

- 暖中性色阶与信息、成功、警告、错误状态色保持不变。
- 普通文字仍满足 4.5:1，功能边框与可见焦点仍满足 3:1。
- 组件继续引用语义角色，不直接绑定品牌或原始色值。
- 公开 PNG 路径保持兼容，本决策不把仍在审阅的 SVG 候选提升为正式真源。
- 本决策只改变静态视觉语义和品牌图片引用，不改变路由、认证、领域状态或持久数据。

## 备选方案

### 方案 A：保留品牌绿九级色阶和全部现有映射

代码无需迁移，但高频绿色继续同时表达品牌、操作、选中与焦点，视觉层级和状态区分问题不消失。

### 方案 B：更换另一个高频品牌主色

蓝青或墨蓝可以缓解品牌绿与成功色相近的问题，但仍让单一品牌色承担过多功能语义，并要求重新
校准品牌资产与全部主题消费者。

### 方案 C：品牌绿稀缺使用，操作与状态独立映射

保留 `#177654` 的品牌识别价值，只在 Logo、favicon、品牌图和明确的签名式强调中使用。主要操作
恢复深灰绿，选中态使用暖中性色，焦点复用功能信息蓝，状态继续使用各自语义色。

## 决策

采用方案 C，并规定：

1. 主题层只保留单一 `--brand-green` 原始 Token；没有真实消费者前不建立品牌绿九级色阶。
2. `--action-primary`、Hover、Active 分别使用固定深灰绿 `#344D42`、`#293E35`、`#20342B`。
3. `--action-subtle` 与选中态使用暖中性色和主文字，品牌绿不承担导航、会话选择或普通标签背景。
4. 键盘焦点使用信息色语义，品牌绿不承担 Focus；成功状态继续使用成功色并配合图标与文案。
5. Web 侧栏和内容空状态使用 `hoox-horizontal-transparent.png`；同一视口只把横版 Logo 作为品牌签名，
   不额外拼接文字版 Hoox 与标语。
6. 如果未来出现至少三个需要明暗变化的真实品牌表面，再新增 ADR 和对比度证据扩展品牌色阶，
   不为预期用途提前保留无消费者 Token。

## 理由

稀缺出现可以保持品牌色的识别强度，同时让高频交互回到稳定、低饱和的操作层。把选中、焦点和
状态分别交给中性、功能和语义角色后，颜色重新表达用途而不是品牌归属，且无需更换现有 Logo。
保留三个操作状态是交互反馈要求，不等于扩张品牌色阶。

## 影响

### 正面影响

- Logo 在中性界面中更醒目，工作台不再被浅绿背景和实体绿按钮反复切割。
- 主要操作、当前选择、键盘焦点与成功状态具有独立语义。
- 品牌 Token 从九级收敛为单一值，减少没有消费者的静态接口。

### 负面影响

- 已经按品牌绿截图或实现的页面需要重新做视觉基线。
- 深灰绿操作色仍有轻微绿色倾向，但它以低饱和度承担高频交互，不作为品牌标识。
- 后续确有品牌色表面时，必须重新建立所需少量色阶与对比度测试，不能从旧名称恢复。

### 安全、数据与兼容

- 不接触凭据、账号、Tenant、Thread、Run、数据库或宿主机能力。
- 既有品牌 PNG 文件继续存在；Web 只把两个可见入口从独立标志或文字组合切换为透明横版 PNG。
- CSS 原始品牌色阶名称尚未形成第三方扩展接口，因此本阶段可以直接收敛。

## 验证

- 主题契约测试证明品牌色不再映射主要操作、选中态或焦点，并继续验证文字、边框和焦点对比度。
- Web 组件测试验证侧栏与内容空状态引用透明横版 PNG，不再输出星形占位或拼接品牌标语。
- Web 样式测试验证横版 Logo 尺寸、品牌占位清理和语义 Token 消费。
- Web 测试、Typecheck、构建及桌面和窄屏浏览器检查验证最终布局。

## 可逆性

可以把语义操作、选中和焦点重新映射到其他固定色值，不需要修改组件类名或业务状态。若恢复品牌绿
色阶，必须通过新 ADR 说明真实消费者、使用上限与对比度，不直接撤销本记录。
