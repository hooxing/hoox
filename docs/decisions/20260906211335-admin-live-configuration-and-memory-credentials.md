# ADR-20260906211335：后台在线配置与记忆密钥托管

- 状态：已接受
- 日期：2026-09-06
- 决策者：Runtime 维护者
- 当前说明：[配置参考](../reference/configuration.md)、[维护者开发边界](../maintainers/runtime-development-boundaries.md)
- 部分替代：[ADR-20260906195752](20260906195752-admin-task-oriented-configuration-and-publication.md) 中运行参数归部署配置、记忆依赖托管模型及 Mem0 密钥仅来自部署的结论。一次保存、自动审计、隐藏内部版本、Skill 直发及权限边界继续有效。

## 背景与备选

日常调整需要编辑环境变量并重启服务，使管理员承担部署维护成本。简化流程的目标是减少审批和重复输入，而不是删除可用的后台设置。仅增加 Mem0 密钥输入会保留记忆依赖模型的隐藏前置条件；直接读取最新配置则会使重试、记忆检索和异步写入在同一 Run 中采用不同配置。

## 决策

1. 模型、记忆和运行参数均采用一次原子保存并生效；并发两项与压缩五项恢复后台入口，未保存时使用部署回退值。页面提供推荐默认值并明确区分推荐与实际已保存状态，不要求原因、审批或手动版本操作。
2. 并发配置在 Worker 调度时读取，读取失败保留最后有效值，初始失败采用部署值；降低上限不取消在途 Run。压缩参数先取现有快照，其次旧 Run 的历史引用，首次配置再取后台当前值或部署默认，执行时受模型输出上限约束。
3. Mem0 API Key 作为只写字段，服务端使用平台主密钥加密，以 `memory:<providerKey>` 绑定用途和供应商。编辑时显式复用同一供应商的既有密文，配置投影、审计及幂等响应不返回明文或密文。旧部署 API Key 继续兼容。
4. 记忆无需先配置托管模型。0062 允许运行快照中模型为空及 generation 为零；首次解析同时固定模型、记忆选择，包括尚未配置的状态。后续配置只影响尚未建立快照的 Run。部署模型的具体参数仍由环境变量提供，已有空模型快照不会因后台新增模型而改变选择。
5. 新部署的记忆作用域秘密从稳定平台主密钥按独立用途派生，不要求管理员填写。已有 `MEM0_SCOPE_HMAC_KEY` 优先保留，迁移 API Key 时不能删除或更换它，否则既有用户记忆标识会改变。平台主密钥必须稳定并备份，不提供普通后台修改入口。
6. 数据库、监听地址、部署角色和平台根秘密仍由部署方配置；不提供任意环境变量编辑器。日常参数的扩展以明确类型、默认值和生效时机为边界。

## 影响、验证与可逆性

该选择延续不可变内部配置与 Tenant/Run 快照，不向管理员增加版本操作。自动化验证覆盖无托管模型时配置记忆、密钥加密与复用、旧新 Run 差异、空配置固定、跨 Tenant 隔离、原子保存、并发冲突以及 Worker 热读取失败回退。

0062 不修改旧迁移或历史配置。数据库存在托管记忆或无模型快照时 down 失败关闭；旧 Worker 不理解这些快照，不能直接回退到旧应用处理它们。回退应采用保留新快照解析能力的修复版本，不删除凭据和运行事实。
