# ADR-20260906211950：工具内部校验字段不进入模型契约

- 状态：已接受
- 日期：2026-09-06
- 关联任务：`fix/hide-runtime-tool-fields`
- 关系：补充 [ADR-0137](0137-durable-tool-failure-model-adaptation.md) 的 durable 失败回执约束；沿用 [ADR-20260828113059](20260828113059-automation-tool-schema-and-error-semantics.md) 的公开参数与内部校验分层，不改变 automation 工具契约

## 背景与选择

`wait_agent` 与 `list_agents` 的非法参数桥需要携带一次性标记，使 Pi 完成参数复制和校验后仍能进入执行器写入失败回执。把标记声明为公开字段，会要求模型理解一个禁止使用的参数；直接删除标记会让 Pi 提前拒绝调用，跳过 Runtime 的失败回执。

选择由公开 schema 派生内部校验 schema，通过仅存在于 Pi Adapter 内存中的显式映射关联。工具工厂公开调用方契约，Pi 执行循环使用内部校验契约；发送 Provider 请求前恢复公开契约。能力摘要和预算均使用公开契约，未注册内部契约的工具保持原有 schema。

不采用按字段名前缀过滤所有工具的方案，避免误删合法业务字段；不采用对象身份或调用顺序识别非法参数，因为 Pi 会复制参数，同批合法与非法调用不能共享无身份的占位值。

## 影响与验证

公开字段仍是模型输入的严格校验真源。调用方伪造内部标记会产生新的内部失败占位，不执行控制面操作；回执、错误码和持久化结构保持原有语义。

自动化测试覆盖公开字段清单、伪造标记拒绝、合法与非法调用混排、真实 Pi 校验与失败回执，以及连续 Provider 请求的 schema 稳定性。

## 可逆性

无数据迁移。可以回退此提交恢复原工具定义；回退会重新暴露内部标记，因此应优先保留公开契约并修复适配器。
