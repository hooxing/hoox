# ADR-20261008150709：后台工具选择与 Run 快照边界

- 状态：已接受
- 日期：2026-10-08
- 当前说明：[工具调用模式](../architecture/tool-calling-modes.md)、[配置参考](../reference/configuration.md)
- 关系：补充 [PTC 模式与受控调用日志](20261003011415-ptc-mode-and-durable-dispatch-journal.md)及[后台日常配置](20260906211335-admin-live-configuration-and-memory-credentials.md)，不替代其执行、权限或恢复协议；沿用[工具用户展示契约](20261004184828-tool-user-presentation-contract.md)。

## 背景

平台管理员需要按场景选择模型可调用的工具。仅在后台展示勾选框或仅隐藏普通模式 Schema，不能限制 PTC 的内部调用，也不能防止子智能体获得平台已关闭的工具。配置保存、正在执行的任务、重启恢复及能力缓存必须采用同一语义，避免相同 Run 在重试时改变权限或重复执行副作用。

## 备选

1. 只在前端隐藏工具：不会约束运行时，拒绝。
2. 全局实时禁用名单：新工具自动启用，且在途任务和恢复会突然改变能力；若要紧急撤权，应另建取消或授权机制，不能复用日常工具选择。
3. 可选启用名单随 Run 快照固定：旧配置保持兼容，显式保存后新工具需要管理员选择；既有 Run 与子智能体共用确定的能力边界，选择此方案。

## 决策

- `RuntimeSettingsConfiguration.enabledTools` 为可选启用名单，使用既有管理员保存、generation 并发控制、幂等和审计链路。不新增环境变量、草稿流程或独立存储。
- 缺字段代表旧行为：启用全部已知业务工具；显式 `[]` 关闭全部业务工具。未知名称、重复、非数组和非字符串都拒绝，不把错误配置解释为全启用。
- 共享协议包拥有平台可选工具目录及规范化规则；后台、服务校验与适配器消费同一目录，数据库迁移通过测试与该目录对齐。目录顺序规范化输入，勾选顺序不改变 Schema、提示词或工厂缓存。
- 保存后在 Worker 首次建立 Run 配置快照时生效。已有快照的执行、恢复 Attempt 与子智能体仍使用原配置；此开关不是即时撤权按钮，也不停止已创建的定时任务或已启动的子任务。
- 普通模式的工具定义和 PTC SDK/内部执行映射从同一实际启用工具集合派生。子智能体能力为平台名单与既有委派名单的交集，不因开启平台工具扩大其既有权限；缺少服务实现的工具不会因勾选而变得可用。
- `run_code` 是 PTC 的隔离编排入口，`collapse_process_for_final_answer` 是普通模式的展示协议，二者不是业务开关。全部关闭后仍可以普通文字答复；PTC 的空工具程序仍可纯计算，但没有业务工具或宿主 IO。
- 关闭 `skill` 后不再为新 Session 恢复或显式加载技能说明。历史对话、已执行结果不删除，不声称清除模型此前获得的信息。
- 工具选择限制的是结构化调用入口，不是沙箱文件 ACL。保留 `exec_command` 时仍能通过命令读写文件；关闭 `read`、`edit`、`write` 不能替代文件系统隔离、授权和宿主安全边界。
- 新增工具必须同时登记目录、提供静态 Schema、受控执行实现和安全的前端展示契约；显式名单不会自动包含新增工具。相同能力配置的工具定义和系统提示词不包含请求级动态事实。

## 影响、验证与可逆性

选择参与 Session 工厂缓存键，实际能力集合继续参与工具 Schema/提示词兼容身份。新迁移 0068 只扩展可选字段并保留完整既有约束，不回填或修改历史 Revision。

验证覆盖协议严格校验、后台保存与失败保留输入、配置规范化、API 防数组自动转换、缓存隔离、普通/PTC 关闭工具强行调用、子智能体交集、恢复与受控副作用链路；迁移测试校验完整约束、目录一致及降级保护，数据库执行由具备临时数据库的集成门禁验证。

管理员可重新勾选并保存，影响之后建立快照的 Run。存在含 `enabledTools` 的任何历史 Revision（包括空名单）时，0068 降级拒绝，不能通过抹去字段或篡改快照回退。代码部署回滚应保留支持该字段的服务和数据库，或先安全排空并核对相应 Run；切回全选不是删除历史事实。
