# ADR-20261115155532：部署后配置沙箱与标题模型

- 状态：已接受
- 日期：2026-11-15
- 部分替代：[首次运行配置](20261115122045-first-run-administrator-and-model-setup.md)中 Sandbox 必须部署前准备的结论；[托管沙箱路由](20260910005916-managed-sandbox-routing.md)中启动必须有环境供应商的前提；[标题生成](0121-low-cost-thread-title-generation.md)中仅由固定租户 Scheduler 消费、凭据只能来自独立环境变量的结论。管理员初始化安全、不可变沙箱绑定、Outbox fencing、输入裁剪与历史目录公开语义继续有效。

## 背景与备选

模型、沙箱、记忆与标题策略属于部署者登录后可管理的应用配置。要求先在环境变量填写供应商秘密，会让后台配置依赖维护者人工完成启动。标题还需要独立选择低成本模型，不能直接跟随主模型切换。

备选是维持完整 env、把所有字段迁入数据库，或保留基础设施部署边界并延后应用配置。完整 env 继续暴露重复配置入口；全部迁入数据库不能解决数据库自身连接和平台解密根的启动依赖。选择第三种方案。

## 决策与影响

Worker 和 Scheduler 允许空沙箱注册表常驻。数据库、S3 和角色安全检查仍是启动门槛；模型与沙箱未配置时 readiness 保持失败，Worker 不领取业务任务。后台保存和应用配置后同一进程自动读取，不把“配置已保存”等同远端可用。显式启用的环境供应商仍必须完整有效；已有实例继续读取固定版本，配置读取失败不得回退。

后台运行设置增加可选标题模型引用和压缩开关。标题引用固定供应商修订和模型 ID，复用该修订的加密凭据，不跟随主模型或供应商后续保存。保存、草稿和发布验证引用存在且模型启用、输出预算可用。Runtime 只额外读取当前活动运行设置引用的精确模型修订：由 Migrator 所有的安全屏障视图公开引用身份，RLS 按该投影授权，不引入 SECURITY DEFINER routine，也不开放全量历史凭据。切换、关闭和取消引用撤销此额外授权。

标题入队在输入事务中读取当前后台开关，缺字段才采用旧部署开关。后台标题消费加入 Worker 已有动态租户维护；Scheduler 保留固定租户兼容消费，双方共享 claim fencing。未配置或读取失败不领取、不消耗尝试；显式关闭把待处理任务收敛为确定性标题。生成请求继续只包含受限首条输入和附件元数据。后台压缩开关按 Run 配置快照固定，部署总开关仍是底层能力门槛。

示例只保留数据库、对象存储、网络信任、进程身份/租约、能力门禁和稳定根秘密；模型、沙箱、记忆、并发与压缩参数保留可选兼容键。已有记忆作用域秘密不得删除，否则会改变已存在的用户记忆身份。首次页面引导管理员、模型、沙箱三步，其他应用设置按需配置。

## 验证与可逆性

自动化验证覆盖空供应商解析、显式部分配置拒绝、动态沙箱配置、标题三态与凭据解密失败、页面保存往返和迁移形状。真实 PostgreSQL 用独立非特权角色验证主模型与独立标题模型读取、精确修订切换撤权、重复 ACL bootstrap 和管理保存路径。

0073 只追加约束和授权投影，不改写历史修订。存在新增字段时 down 拒绝，回退必须先向前处理配置；不删除密钥或实例绑定。环境回退兼容继续保留。当前操作入口归[配置参考](../reference/configuration.md)与[开发指南](../development.md)。
