# 托管 Sandbox 供应商路由验收

本文记录 2026-09-10 北京时间对后台托管 Sandbox 供应商配置与 Demo 部署的验收证据，供维护者区分已实现能力、已部署状态与尚未验收的范围。当前契约见 [Sandbox Provider](../architecture/sandbox-providers.md#后台配置与分配)，决策见[后端管理 Sandbox 供应商配置与版本固定](../decisions/20260910005916-managed-sandbox-routing.md)。

## 环境

- 代码：`origin/main` 合并提交 `cdff1d2`（PR #27）。
- 自动化门禁：持续集成 run 34436099299 成功；Demo 持续部署 run 34436545373 成功。
- Demo：`https://hoox.aisay.cc`，Oracle 春川主机，Runtime 容器使用 host 网络。
- 真实供应商探测在本机 Windows 调用生产探测函数 `probeConfiguredSandbox()`，凭据只取自本机 `.env`，未进入仓库或验证输出。

## 实测结果

| 检查 | 结果 |
| --- | --- |
| 腾讯云 AGS 探测路径 | 通过，12.2 秒；覆盖真实创建、模板 Python 与 Node 依赖、文件写入读取、暂停恢复后仍可读、销毁并确认 `not_found` |
| E2B 探测路径 | 通过，5.5 秒；检查项与 AGS 相同 |
| Cube 探测路径 | 失败，0.4 秒收敛为“创建结果未知”；本机无法连接 Cube 服务，因此不作为可用供应商发布 |
| Demo 后台「沙箱服务」 | 可访问；提供供应商连接、模板、TTL、操作超时、创建与恢复超时、暂停保留时间、空闲暂停或销毁，以及单供应商与按权重分配 |
| Demo 后台当前状态 | 尚未发布托管配置，页面明确显示新实例沿用部署配置 |
| Demo 真实任务 | 新建会话执行 `python3 -c "print(6*7)"`，CubeSandbox 返回 stdout `42`、退出码 0；任务结束后工作区按空闲策略暂停 |

探测与任务时点均为 2026-09-10。

## 未完成与边界

- Demo 尚未发布托管供应商配置，新实例仍来自部署环境配置；托管路由在 Demo 上接管新实例尚未验收。
- 托管配置首次发布需要管理员在浏览器中录入供应商密钥。本机 Codex 浏览器运行时拒绝对 `type=password` 字段写入，`fill`、逐键输入、`Ctrl+V` 与浏览器粘贴通道均不生效，该步骤必须人工完成。
- 本次记录时本地开发基础设施的 uu 端口映射不可达，`127.0.0.1` 的 15432、29000、13000、18080 全部返回 `ECONNREFUSED`，因此本轮没有重跑依赖 PostgreSQL、MinIO 与 Cube 的本地验证。
- 未覆盖：Demo 上的权重分配实际比例、已有实例的版本固定、Worker 重启后的恢复、Scheduler 清理、暂停保留到期，以及春川到目标地域的真实延迟比较。

这些证据仅属于上述提交、环境和时点，不代表后续版本的持续保证。
